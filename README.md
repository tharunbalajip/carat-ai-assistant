# CARAT AI Assistant 🤖

CARAT is a Python-based voice assistant that can listen to voice commands and perform useful tasks on a Windows computer.

## Features

- 🎤 Voice command recognition
- 🔊 Text-to-speech responses
- 🔎 Google web search
- 📝 Create and save notes
- 🧮 Voice-based calculator
- 🕐 Tell the current time
- 📅 Tell the current date
- 🖥️ Open Windows applications
- 🌐 Open Google, YouTube and GitHub
- ❓ Built-in help command
- 🛑 Voice command to stop CARAT

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Google Speech Recognition
- Windows SAPI5

## Requirements

- Python 3.12+
- Windows operating system
- Working microphone
- Internet connection for speech recognition and web search
